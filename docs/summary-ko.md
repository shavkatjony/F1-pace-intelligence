# F1 Pace Intelligence · 한국어 요약

**한 줄 요약:** 공개된 F1 타이밍 데이터(2022–2026)로 레이스 전에 각 차량의 레이스 페이스를
불확실성 범위와 함께 예측하고, 레이스 후에 그 예측을 채점하는 엔드투엔드
데이터 사이언스·ML·AI 프로젝트입니다.

**문제:** 대부분의 F1 데이터 프로젝트는 이미 일어난 일을 보여 줍니다. 이 프로젝트는 레이스 팀
엔지니어의 질문에 답합니다. "연습 주행과 예선이 끝난 뒤, 일요일 레이스에서 각 차량은 실제로
얼마나 빠를까? 얼마나 확신할 수 있을까? 타이어와 피트 스톱은 어떻게 해야 할까?"

**만든 것**
- 데이터 파이프라인: FastF1에서 545개 세션, 297,724랩을 수집해 DuckDB 웨어하우스로 정제
  (데이터 검사 21개, 모든 랩에 하나의 사유 코드)
- 예측 모델: 모든 서킷과 연도에 하나의 가중 회귀 모델, walk-forward 백테스트,
  베이스라인 5개, 80% 예측 구간
- 전략 결정: 타이어 마모와 피트 손실로 1·2·3스톱을 4,000번 시뮬레이션하고,
  확실하지 않으면 "명확한 결정 없음"이라고 답함
- 공개 기록: 레이스 30분 전까지 예측을 GitHub에 고정하고, SHA-256과 CI로 사후 수정을 막으며,
  레이스 후 자동 채점하는 구조. 2026 시즌 1–17라운드로 리허설했습니다(사후 실행으로 표시).
  2026년 10월부터 F1 타이밍 데이터에 로그인이 필요해져 새 레이스를 무료로 받을 수 없으므로,
  레이스 전에 실제로 고정한 주말은 아직 없습니다.
- 디브리프: 랩 타임 차이를 구간 종류별로, 레이스 차이를 페이스·타이어·트래픽으로 분해
- AI 레이스 엔지니어: 읽기 전용 도구 8개를 쓰는 LLM 에이전트(Claude, Ollama)와
  50문항 자동 채점 시험
- 공개 앱: GitHub Release에서 Docker 이미지를 빌드·테스트해 Render 무료 서버에 배포(읽기 전용)

**주요 결과**
- 모델 선택에 쓰지 않은 2025–26 시즌에서 예선 후 오차 0.548% (랩당 약 0.49초),
  가장 좋은 베이스라인(0.589%)보다 정확
- 80% 예측 구간 안에 실제 결과의 79.9%가 포함 (불확실성을 정직하게 표현)
- 드라이 레이스 78개 재현에서 스톱 횟수 판단 일치율 58% ("항상 1스톱"은 46%)
- AI 시험(2026년 11월 8일): Claude 50문항 모두 통과, 공개되지 않은 정보(연료, 세팅 등)를
  묻는 함정 질문 5/5 거절, 1회 실행 비용 $1.53

**데이터 기준:** 2026 싱가포르 그랑프리(10월 11일)까지의 데이터입니다. 온라인 데모는 날짜가 표시된
데이터 스냅샷이며, 실시간 데이터가 아닙니다.

## AI 레이스 엔지니어는 어떻게 동작하나요?

AI는 데이터베이스를 직접 알지 못합니다. 질문을 받으면 어떤 도구가 필요한지 고르고,
제 코드가 그 도구(예: DuckDB에 대한 읽기 전용 SQL, 예측 조회, 타이어 결정 조회)를 실행해
결과를 돌려줍니다. AI는 그 결과만 사용해 답을 쓰고, 숫자마다 출처 도구를 표시합니다.
연료량, 세팅, ERS처럼 공개 데이터에 없는 정보는 추측하지 않고 "공개되지 않음"이라고 답합니다.
SQL은 SELECT만, 알려진 테이블만, 최대 행 수 제한으로 보호됩니다.
성능은 웨어하우스에서 정답을 계산하는 50문항 시험으로 자동 채점하며,
같은 시험으로 Claude API와 로컬 모델(Ollama)을 비교할 수 있습니다.
