# Experiment register

An index of the investigations that shaped F1 Pace Intelligence. Each row is one question that was tested against the data. **Status** uses the labels from the [research archive](README.md#evidence-levels), plus *Adopted* or *Rejected* when the result decided between options. Dates are the first-commit dates of the decision records.

Scopes used below: **tune years** = 2023–24 (settings chosen here), **test years** = 2025–26 (37 weekends, 726 driver-races per checkpoint, never used for choosing), **all forecast years** = 2023–26 (78 dry weekends).
