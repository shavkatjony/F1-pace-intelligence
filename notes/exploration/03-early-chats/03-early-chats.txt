18. What you can realistically use
This is actually good news.
You do not need F1's private team data to make the project substantial.
There are currently public sources that give you a surprisingly large amount of genuine F1 data.
OpenF1
OpenF1 currently provides historical F1 data from 2023 onward for free, including telemetry, timing and session data. Its real-time data requires a paid subscription. 
It currently exposes things including:
car telemetry
laps
sectors
location
intervals
positions
pit stops
stints
weather
race control
session results
starting grid
drivers
championship data
teams championship

FastF1
FastF1 is a Python library specifically designed to work with F1 results, schedules, timing and telemetry. It also supports the Jolpica F1 API for broader historical F1 information. 
Its documentation/source describes telemetry channels such as speed, RPM, gear, throttle, brake, DRS and positional coordinates. 
Jolpica F1
Jolpica is now the successor to the old Ergast API and provides broader structured historical information such as circuits, drivers, constructor standings, driver standings, laps, pit stops, qualifying, races, results, seasons and sprint data. 
So you can combine sources rather than forcing everything through one API.
